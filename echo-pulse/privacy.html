Pengembang: Lalu Lalang Studio, merek dari PT. Tangrasula Tekno Kreatif (Indonesia)

(English summary at the bottom.)

Ringkasan

Echo Pulse gratis sepenuhnya: tanpa iklan, tanpa pembelian dalam aplikasi, tanpa akun. Kami tidak mengumpulkan, menyimpan di server, atau membagikan data pribadi apa pun.

Data yang disimpan di perangkat

Kemajuan Journey (stage yang terbuka dan bintang), rekor Endless, kalibrasi ketukan, dan pengaturan (musik, efek suara, getar, grafis ringan) disimpan hanya di perangkat Anda. Data ini tidak pernah dikirim ke kami atau ke pihak lain.

Daftar game lain ("More games")

Menu More games mengunduh daftar game kami dan ikonnya dari situs kami (lalulalangstudio.github.io), yang di-host oleh GitHub Pages. Permintaan ini tidak membawa data pribadi atau ID apa pun dari aplikasi. Seperti situs web lain, server GitHub dapat mencatat alamat IP dan informasi teknis permintaan sesuai Pernyataan Privasi GitHub. Daftar terakhir disimpan di perangkat agar menu tetap tampil saat offline. Menekan tombol Google Play membuka Play Store, yang diatur oleh Kebijakan Privasi Google.

Izin aplikasi

Echo Pulse hanya menggunakan akses internet (untuk daftar More games) dan getaran (efek getar saat bermain, bisa dimatikan di Settings). Aplikasi ini tidak memakai ID iklan dan tidak meminta izin lokasi, kamera, mikrofon, kontak, atau penyimpanan.

Penghapusan data

Semua data ada di perangkat Anda dan dapat dihapus dengan menghapus aplikasi atau menghapus data aplikasi di pengaturan Android. Kami tidak memegang data Anda di tempat lain.

Anak-anak

Echo Pulse tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Perubahan & kontak

Kebijakan ini dapat diperbarui sewaktu-waktu; versi terbaru selalu tersedia di halaman ini. Echo Pulse dikembangkan oleh Lalu Lalang Studio, merek dari PT. Tangrasula Tekno Kreatif. Pertanyaan: lalulalangstudio@gmail.com.

English summary

Echo Pulse is developed by Lalu Lalang Studio, a brand of PT. Tangrasula Tekno Kreatif (Indonesia). The game is completely free: no ads, no in-app purchases, no account. We do not collect, store on a server or share any personal data. Journey progress, Endless records, tap calibration and settings are stored only on your device. The More games menu downloads our game list and icons from our website (lalulalangstudio.github.io, hosted on GitHub Pages); the request carries no personal data or identifiers from the app, though GitHub's servers may log the IP address and technical request details under the GitHub Privacy Statement. The last list is cached on the device. Tapping Google Play opens the Play Store, governed by Google's Privacy Policy. The app uses only internet access (for the More games list) and vibration (can be turned off in Settings); it does not use the advertising ID and does not request location, camera, microphone, contacts or storage permissions. You can delete all data by uninstalling the app or clearing its data. Contact: lalulalangstudio@gmail.com.
